# Employee Registration System 🚀

Este é um sistema desenvolvido em **Java** para console que simula o gerenciamento e cadastro de funcionários de uma empresa, aplicando conceitos fundamentais de Orientação a Objetos (OO) e manipulação de listas.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git / GitHub

## 🎯 Funcionalidades
* Cadastro de múltiplos funcionários com ID, nome e salário.
* Validação para impedir o cadastro de funcionários com IDs duplicados.
* Aumento salarial baseado em uma porcentagem informada pelo usuário.
* Listagem completa de todos os colaboradores registrados após as atualizações.

## 💡 Conceitos Aplicados
* Encapsulamento e classes (Entidades)
* Manipulação e busca dinâmica em Listas (`List` e `ArrayList`)
* Expressões lambda e streams para filtragem de dados
